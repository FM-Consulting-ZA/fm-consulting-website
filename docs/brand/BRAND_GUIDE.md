# FM CONSULTING ZA - Brand Guidelines
## Ruthless Minimal Identity

### 1. LOGO
Primary Mark: Custom FM ligature where F and M share a single vertical stroke.
Broken Circle above: Represents breaking the cycle, strategic disruption.
- Icon Only: For favicon, profile, watermark
- Full Lockup: Icon + FM CONSULTING ZA

### 2. COLORS
- Primary Black: #000000 (main logo, text)
- Pure White: #FFFFFF (backgrounds)
- Secondary Grey: #B0B0B0 (subtext)
- Off White: #F5F5F5 (cards, sections)

### 3. TYPOGRAPHY
- Headings: Modern Geometric Sans (e.g., Space Grotesk, Inter, Sora) - Bold
- Body: Inter / Helvetica Neue - Regular
- Tracking: Wide for CONSULTING ZA (200 letter spacing)

### 4. USAGE
- Minimum clear space: Height of the broken circle around logo
- Don't stretch, rotate, add shadows or gradients
- Black logo on white, White logo on black only
